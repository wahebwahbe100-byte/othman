So funktioniert das Anfrageformular

Die eingegebenen Daten werden zunächst ausschließlich im Browser verwendet, um eine Nachricht zusammenzustellen. Dieses Formular übermittelt die Angaben nicht an einen eigenen Formularserver und speichert sie nicht im lokalen Browserspeicher.

Wenn Sie „In WhatsApp öffnen“ wählen, werden die Angaben in der WhatsApp-URL an den externen Dienst übergeben. Die Nachricht senden Sie anschließend selbst in WhatsApp ab. Alternativ können Sie uns telefonisch kontaktieren.

Externe Links

Die WhatsApp-Schaltflächen führen zu einem externen Dienst. Dieser wird erst beim Anklicken geöffnet. Auf der Website ist kein WhatsApp-Chat-Widget eingebettet.

Technischer Stand dieser Vorlage

Schriftarten, Bilder und Symbole werden lokal mitgeliefert. Die Vorlage bindet keine Analysewerkzeuge, Werbepixel, externen Karten oder extern geladenen Schriftarten ein. Der Website-Code setzt keine eigenen Cookies.
